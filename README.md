# TP HTML & CSS

## Présentation

Ce dépôt contient un TP réalisé dans le cadre de mon Bachelor Informatique à l'IPSSI Paris.

Ce projet a pour objectif de mettre en pratique les connaissances acquises au cours de ma formation, notamment dans le développement web.

## Technologies utilisées

- HTML5
- CSS3

## Objectifs pédagogiques

- Découvrir et pratiquer la structure d'une page web avec HTML.
- Apprendre à mettre en forme une page avec CSS.
- Comprendre l'organisation des fichiers d'un projet web.
- Développer mes compétences en intégration web.


*Projet personnel à but pédagogique.*
